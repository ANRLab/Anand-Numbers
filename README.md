# Anand-Numbers
On Positive Integers Satisfying n = s10(n)τ(n): The Anand Numbers  Zenodo DOI: 10.5281/zenodo.23874682
The Anand Numbers
Definition
A positive integer n is called an Anand Number if

n = s10(n) * tau(n),

where s10(n) is the decimal digit sum and tau(n) is the number of positive divisors of n.

Main Result
The equation

n = s10(n) * tau(n)

has exactly three positive integer solutions:

1, 80, 108.
